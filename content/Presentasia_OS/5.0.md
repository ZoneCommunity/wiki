# Presentasia OS 5.0 Kaleidoscope

Presentasia OS 5.0 Kaleidoscope is the fifth version of Presentasia OS.

## Applications and features

Presentasia OS 5.0 was the first version of Presentasia OS to include shaded, glossy icons. This version also allowed for wallpaper changing but was limited to 4 preset backgrounds.
