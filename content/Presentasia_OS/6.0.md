# Presentasia OS 6.0 Squared

Presentasia OS 6.0 Squared is the sixth version of Presentasia OS. It is actually the seventh version made by Presentasia: there is a very obscure finished version of Presentasia OS 6.0 that was scrapped completely in favor of the version known today.

## Applications and features

This was the first version of Presentasia OS to feature the present logo (angular style). Old versions of the logo were still featured in the OS, especially in the Files app and Writasia app. This was the only version to use a different icon layout on the desktop (unlike other versions, which used the Matrix interface). Internet Atlas was replaced with WeBrowse, and it included a Calculator app and customizable passwords for the Admin account.
