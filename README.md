# PPTOS Wiki

PowerPoint OS Network's official encyclopedia for any and all PPTOSes.
Live site: **https://wiki.pptos.net**

## What this is

This repo is the wiki behind `wiki.pptos.net`, the PowerPoint OS Network
wiki. Each article is a Markdown file under `content/`. A Python
build script (`build.py`) turns those files into static HTML using the
template in `template/`, and Cloudflare Pages serves the result.
