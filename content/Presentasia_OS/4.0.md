# Presentasia OS 4.0 Matrix

Presentasia OS 4.0 Matrix is the fourth version of Presentasia OS. This version is the final Classic Presentasia OS (retaining many of the same icons as prior versions). It is recognized for its theme, "Sleek Silver".

## Applications and features

This was the first version of Presentasia OS that used Macros.
