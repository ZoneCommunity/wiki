# All versions

Every zeqOS version, in order.
Click a version to open its page, at `wiki.pptos.net/zeqOS/<Version>`.

## Versions

| Version | Status |
| --- | --- |
| [zeqOS Makalu](/zeqOS/Makalu/) | First public release |
| [zeqOS Culebra](/zeqOS/Culebra/) | Unknown |
| [zeqOS Fluorite](/zeqOS/Fluorite/) | Never released |
| [zeqOS Natrolite](/zeqOS/Natrolite/) | Released |
| [zeqOS Rhodonite](/zeqOS/Rhodonite/) | Canceled |
| [zeqOS Chabazite](/zeqOS/Chabazite/) | Latest stable release |
| [zeqOS Barrerite](/zeqOS/Barrerite/) | Never released |

## Notes

- [zeqOS Chabazite](/zeqOS/Chabazite/) is the latest version of zeqOS, named after the mineral.
- [zeqOS Rhodonite](/zeqOS/Rhodonite/) was canceled, and its development was reset into Chabazite.
- [zeqOS Fluorite](/zeqOS/Fluorite/) was never released, and was likely replaced by Natrolite.
- [zeqOS Barrerite](/zeqOS/Barrerite/) was meant to replace Chabazite, but was never released.
