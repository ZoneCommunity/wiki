# Presentasia OS 2.0 TreeFrog

Presentasia OS 2.0 TreeFrog (stylized as (Presentasia) OS 2.0 TreeFrog or Presentasia Tree Frog) is the second version of Presentasia OS, released on August 13, 2012. This was the first Presentasia OS to have a codename.

## Development

During development, Presentasia OS 2.0 was named Amphibian. Some called Presentasia OS 2.0 the green edition of Presentasia OS 1.0.

## Applications and features

Presentasia OS 2.0 included the same apps as Presentasia OS 1.0, however, Office, Spreadsheet, and Store were removed. Presentasia OS 2.0 included the Presentasia Center application and FlatView mode.
