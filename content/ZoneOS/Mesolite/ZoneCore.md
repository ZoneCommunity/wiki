# ZoneCore

**ZoneCore** is the core used within ZoneOS Mesolite. It is the
current core of ZoneOS, powering [Mesolite](/ZoneOS/Mesolite/).

## Overview

It provides the window system, the UI toolkit, input handling,
and the filesystem. ZoneCore lacks an internal versioning system.

## History

ZoneCore began development in late 2024, a week before ZoneOS
Mesolite itself had officially entered development.

It has grown to be the most advanced core of ZoneOS to date.
