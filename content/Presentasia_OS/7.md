# Presentasia OS 7

Presentasia OS 7 is the seventh version of Presentasia OS. It is one of the only versions of Presentasia OS that was released without a version name.

## Development

Presentasia OS 7 was codenamed "Glow" during development.

## Applications and features

Presentasia OS 7 still contained elements that were featured in prior versions, such as limited wallpapers and the interface. This version ditched the style of 6.0 and went back to Matrix UI like all prior versions of Presentasia OS (excluding 6.0). The desktop had made its way back to the MatrixView mode. It was also the first Presentasia OS to remove start buttons and add-ins for web apps.

## 7.1

The 7.1 update was released a day after the 7.0 launch, fixing the Background Changing issues, while also removing password protection from the file.
