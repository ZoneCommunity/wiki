# zeqOS Natrolite

**zeqOS Natrolite** was one of the first PPTOSes ever to have movable windows with ActiveX elements.

## Overview

In the File Manager, you could open and edit files. All of that fit in only 1 slide, with a size of only 4.55 MB. In total, there were 14 service packs. Natrolite was open sourced in early 2022.
