# zeqOS

**zeqOS** is a series of PPTOSes developed by Zulo.

## Overview

zeqOS is a family of PowerPoint OSes made by Zulo. It began with [zeqOS Makalu](/zeqOS/Makalu/), the first zeqOS version, and ran through seven versions in total: Makalu, [Culebra](/zeqOS/Culebra/), [Fluorite](/zeqOS/Fluorite/), [Natrolite](/zeqOS/Natrolite/), [Rhodonite](/zeqOS/Rhodonite/), [Chabazite](/zeqOS/Chabazite/), and [Barrerite](/zeqOS/Barrerite/).

The early versions were multi-slide PPTOSes, without the moving windows that Natrolite later introduced. Rhodonite was shown off in a video in November 2020, but was canceled, and its development was reset into Chabazite. Zulo’s latest version of zeqOS is called zeqOS Chabazite, named after the mineral. Chabazite was the first version to introduce ZCS, the zeqOS Coding Structure, the programming language used to make zeqOS apps, and it is now end-of-life. Barrerite, the version meant to replace it, was never released, and zeqOS is now defunct.

## History

zeqOS began development in early 2020 with zeqOS Makalu, the first version to be released to the public. The early versions were multi-slide PPTOSes, without moving windows. Culebra followed sometime after Makalu's release and was only ever used by beta testers, and Fluorite, the first known version to create applications fully in VBA, was never released.

Natrolite was the turning point, becoming one of the first PPTOSes ever to have movable windows with ActiveX elements, all in a single slide. It was open sourced in early 2022.

Rhodonite was shown by Zulo in a video that premiered on November 8, 2020, but it was canceled, and development was reset in late 2020 to a new core called Zento. That reset became Chabazite, the latest version of zeqOS, released on July 17, 2021. Chabazite introduced ZCS, the programming language used to make zeqOS apps, and is now end-of-life. Barrerite, meant to replace Chabazite with the new ZT2 core, was never released, and zeqOS is now defunct.

## Cancellations

Three versions of zeqOS never made it to release. Fluorite was likely replaced by Natrolite. Rhodonite was canceled, and its development was reset into Chabazite. Barrerite, meant to replace Chabazite, was never released either.

Chabazite has since reached end-of-life. With no successor ever released, zeqOS is now defunct, and Chabazite remains its final version.
